# EduGenie – AI Learning Assistant

EduGenie is an AI-powered educational application designed to help students learn and understand different subjects easily.

## Features

- Intelligent Question Answering
- Concept Explainer
- Multiple academic subjects
- AI-powered learning assistance
- Simple and user-friendly interface

## Subjects

- Mathematics
- Physics
- Biology
- History
- Computer Science
- General Knowledge

## Technologies Used

- Google AI Studio
- TypeScript
- React
- Vite

## Project

EduGenie helps students ask questions, understand concepts, and improve their learning with the help of Artificial Intelligence.
